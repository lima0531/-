# 标准修改单：新取得的公开草案原件与正式文件边界

观察日期：2026-10-09。本目录新增取得两份真实公开PDF原件，均为**征求意见稿及其编制说明**。这补充了标准演变档案，不关闭任何车型参数、配置身份、工况或低温报告缺口。

全国汽车标准化技术委员会汽车节能分技术委员会（TC114SC32）的[原公示页](https://zxd.catarc.org.cn/zxd/portal/zqyj/488)明确给出公示发布日期 **2024-05-13**、意见截止日期 **2024-07-12**，正文和附件均对应GB/T 18386.1—2021《电动汽车能量消耗量和续驶里程试验方法 第1部分：轻型汽车》国家标准第1号修改单。

附件从公示页的真实链接取得，均为HTTP200并通过PDF解析、正文目标编号、封面草案标识和SHA核验。[独立只读复核](independent_draft_readonly_review.json)的8项检查全部通过。公示日期晚于2023-12-10；不据此回填历史车型试验标准版本，也不能替代同配置车辆的附录A检测报告。

另跟进公示站真实“标准公告”菜单及第2、3页，第2页实际列出[2025年第19号一般批准公告](https://zxd.catarc.org.cn/zxd/portal/bzgg/365/bzgg)，题名为批准416项推荐性国家标准和3项修改单，落款2025-08-01。该页面只展示17项汽车新标准子表，**全文未出现18386.1目标编号，也没有目标修改单附件链接**。因此只确认该一般公告本身，不把2025-08-01或第19号填入目标修改单的正式字段。SAMR原全文公开通知另一路本轮403，见[此前官方核查](../public_standard_amendment/README.md)。

[国家标准文献馆详情页](https://www.ndls.org.cn/standard/detail/9fb455d9b0f4f957604e59ea3abf3510)也取得HTTP200，显示基础标准的日期及状态；本页没有补出对应修改单正式信息。基础标准2021-03-09发布、2021-10-01实施与修改单日期分别处理。

本目录共8个实际网络响应：草案公示、文献馆、两PDF附件、公告菜单、第2/3页和第19号公告正文。每份原响应保留请求URL、UTC观察时间、TLS验证、状态、文件字节与SHA。[逐响应核验清单](actual_requests_verified.json)、[严格字段表](标准草案与正式字段_严格区分.csv)及[摘要](standard_extra_summary.json)可直接查看。正式修改单发布日、实施日及目标公告号仍未核定；不声称不存在正式修改单。
