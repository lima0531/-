## 你可以先做的两件事

1. 用本人浏览器尝试[官方产品/能耗查询入口及交回格式](public_configuration/人工官网查询_操作与交回格式.md)。能耗官网可打开，正常查询先要求滑块验证；本环境未取得标签记录。产品公告公开服务入口本次403，旧入口502。可尝试不等于保证那里有目标材料，也不等于认证接口不能访问的原因。
2. 优先向江铃索取JX税48历史配置总能量。已知NC010086及L173C01/L173G01只是询证线索；需两储能版本各自能量/质量和正式税配置对应依据，不能乘416kg倒算。其余按[企业分组与模板](user_handoff/README.md)分批索取。

每份材料保留提供单位、原始文件、型号/配置/版本、报告编号、试验/申报日期和适用时间。企业交付的历史报告可补证历史技术事实；若要进入2023-12-10公告前公开信息的冻结输入，还须另证当时的信息可得性。材料可能仍为多配置，不承诺JX一补即把numeric_ready增加1。
