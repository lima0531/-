# 第一批公告公共CDX有界核查

本轮仅查两个已知URL：国家税务总局法规库具体页 `https://fgk.chinatax.gov.cn/zcfgk/c100013/c5207263/content.html` 和内蒙古税务转载页 `https://neimenggu.chinatax.gov.cn/zcwj/zxwj/201809/t20180929_419165.html`。每个URL各查2014年HTTP200快照及不限年份最早一条HTTP200索引记录，总计四次实际网络请求，均保持TLS验证及原代理环境，无重试或重放快照。

四次响应均为HTTP200，原始响应体均为 `[]` 加换行，共3字节，SHA256均为 `37517e5f3dc66819f61f5a7bb8ace1921282415f10551d2defa5c3eb0985b570`。这证明本轮对这些确切URL的公共CDX查询没有观察到快照记录；接口没有被拒绝。未取得2014快照或任何最早快照时间，不给本轮历史公开观察上界，也不声称公告在2014没有公开、所有旧URL都没有快照或全网历史首发已核定。

此前保存的round3免征第一批page_manifest记录及其内蒙古HTML未给出更早MIIT公告URL；页面备案链接不能替代公告来源，2023年“减免第一批”也未混入。此界限不等于完整搜尽MIIT历史URL。

`*.response.bin` 保存响应体，`*.receipt.json` 保存确切请求URL、实际状态/响应头/时间/SHA，`conclusion.json` 汇总证据和推断边界。复跑 `python probe_cdx.py` 会复用四份已保存回执，避免重复网络请求；若回执被删除则会发新请求，因此保存后的目录应作为本次记录整体保留。首次两个查询的回执按当时字段保存，查询阶段由确切请求URL体现；最早记录查询另有query_period字段。
