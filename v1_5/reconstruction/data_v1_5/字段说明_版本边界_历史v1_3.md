# v1.3字段及版本边界

本版已加入73条遗漏历史撤销，修正47条第27批撤销的错批日期。风险集2805、输入准备2424、单值不足381。2024撤销共503=风险内496+风险外7，撤销后再列入5为其中子集。

读取五档表请用 `官方技术清单/五档数值层_逐型号归属与判据.csv`；读取风险外2024撤销请用 `官方技术清单/2024撤销观察_风险集外型号.csv`。带“2877行”或“8型号”的旧名仅兼容入口，真实本版行数分别2805和7。

`potential_event_count`表示可能最后事件候选数。`0001-01-01`表示未知下界占位，不能当真实日期。月份状态基于月末，不表示整个月所有车辆均有同一法律资格。`publish_date_exact`为主管部门现存页面明确登记公开观察日，不认证历史全球首次上线。

旧9份撤销语义表仍为3007条出处记录；第27批在此表的正式观察字段和公告批次已纠正，`撤销事件日_raw`保留原上传值用于追溯。新增两份撤销完整2020行另列；9+2来源记录合计5027行，不代表5027个唯一型号。原件逐表综合枚举含多种类别，不能作为纯电乘用车全总体计数。

型号级外部产品名称佐证见 `车辆类别外部证据/`，它不认证M1证书、企业法律主体或跨目录同配置。未取得的低温检测、身份材料、逐车制造日期和因果证据继续保留未知及认证标记0；认证0不表示已认定不合格。官方清单标记为事后信息，不回填为2023-12-10之前特征。
