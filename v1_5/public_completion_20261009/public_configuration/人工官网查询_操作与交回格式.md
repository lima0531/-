# 两个真实公开入口及材料如何交回

本轮尚未取得这些系统中的车型结果。下列步骤是已核实前端提供的公开查询路径，不保证目标一定收录、能量字段一定展示，也不把查询网站的显示值直接认定为购置税配置原值。

## 能源消耗量标签

入口：[中国汽车能源消耗量查询](https://yhgscx.miit.gov.cn/)。装备中心真实首页链接与该官网首页均已保存。本轮官网前端SHA256为 `ef48b95f266c08103f35e84054546d982dbe7cba64fd3f2837138097138cab43`，见[前端原字节](portal/energy_script_31.js)和[查询边界证据](portal/energy_frontend_user_query_boundary.json)。

1. 用本人浏览器打开，分别查看“新版能耗数据”和“旧版能耗数据”；选择纯电动车/新能源对应分类。
2. 按[36目标精确型号](36目标_逐型号公开探查与精确询证台账.csv)输入“车辆型号”，先查 `GTM6470BFEBEV`、`CC7000CG00FBEV`；JX可另查 `JX6550T-M5BEV`。保留完整型号后缀，不使用近似型号代替。
3. 正常完成网站显示的滑块验证。如果出现网络或验证错误，记下错误即可，不能将其记作没有该车型。
4. 对目标的全部结果，保留“能耗配置ID”、企业、通告日期、启用/废止日期和“完整标签”。查询全部历史版本，不只选当前最新。
5. 若网站提供原PDF/图片下载，就保留原文件；没有下载按钮，可用浏览器打印为PDF，并同时保存地址、查询时间和页面显示日期。截图可以帮助定位，但字段核验仍优先原标签/原文件。

**本轮没有查询结果、没有拿到报告。** 能耗配置ID也不自动等于推荐目录的NC配置ID或购置税申报ID。新版/旧版页面标签不等于已经核定具体车型的试验工况/标准版本；实际标签必须逐版本读取。若返回后于2023-12-10的版本，只能作为后续线索或后期数据，不能回填公告前冻结输入。能耗标签可能没有电池能量/质量；它更可能帮助报告版本、工况、类别或配置定位，仍需匹配证据。

## 交回材料的最小信息

| 字段 | 要求 |
|---|---|
| 完整型号 | 保留所有后缀和连字符 |
| 申报/配置标识 | 公告产品ID、NC推荐ID、税目录申报配置ID分别保存，不合并 |
| 原版本日期 | 页面/报告/原申报版本中的日期原样保存；不把当前访问日当历史发布日期 |
| 参数/配对 | 每套电池对应的总能量kWh、总质量kg、公差定义和续航；不只提供销售车型名 |
| 来源 | 原网址、原下载文件、报告编号和机构/企业；打印PDF注明打印时间 |
| 冻结输入可得性 | 若拟进入2023-12-10之前输入，需另外证明当时材料已可得 |

36型号和285版本的材料并非全部需要立刻找齐。前者分19个原文/上下文企业名；285版本分43个原文企业名，具体型号和NC ID已放入[企业分组表](43原文企业_跨目录身份询证分组.csv)。企业更名、委托主体或检测机构身份仍须按文件核实，当前分组没有合并法律主体别名。
