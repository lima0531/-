# 风险集2877→2805：来源证据与版本阶段

实际变化是 **2877−73＋1＝2805**。它发生在此前v1.3事件重建阶段：补入73条已公开但旧事件表遗漏的历史正式撤销，再修正一组错挂公告批次/日期的既有撤销，使1个型号恢复公告前在册。本轮v1.5没有调整风险集。这里的风险集仍按2023-12-10截点同时满足`membership_announcement_cohort=1`和`announcement_active_observed=1`确定；3328研究成员和原冻结1991成员始终不变。

73个移出型号分别来自以下两份完整官方附件。每个型号在旧事件表中只有一条较早列入，且其列入日期上界严格早于新增撤销观察日；补入后截至冻结点的最新可观察动作变成撤销。两组型号不重叠，也不属于第27批日期修复的47型号集合。

完整73个型号集合、逐条原件SHA、公告URL和原表位置见[风险集变动_74型号逐源对照.csv](风险集变动_74型号逐源对照.csv)，该表另外包含唯一恢复型号`CSA6461FBEV3`。它的旧事件顺序是“2019-12-10第28批列入→2020-06-02第32批撤销”，导致公告前判为已撤销。SHA为`c388317a1453e6b139a2a67bd21e4b5818d6711b0982feb55626f0ac886783ff`的原件实际关联第27批较早主管部门页2019-10-25；原挂第32批日期不成立。修正后真实已取得事件顺序为“2019-10-25第27批撤销→2019-12-10第28批列入”，因此恢复风险集。47条既有事件及其来源记录修正中，只有这个型号改变2023-12-10风险成员资格；其余46个没有使风险集人数变化。既有事件ID和来源ID保留。

本地可追溯阶段是：上传精简包及仅补日期v1.2为2877；只新增73撤销的中间构建为2804；加入第27批错批日期修正的最终v1.3为2805。中间摘要生成于2026-10-08 14:13:51 UTC、最终摘要于14:45:42 UTC，基底分别是`data_v1_2`和`corrected_source_base`。构建脚本有意读入新来源并重新生成风险状态，固定使用`data_v1_3`输出目录；旧中间摘要/manifest随后存入`intermediate_2804`。因此本地2804与2805是同一v1.3工作阶段的先后产物，有各自来源、时间及文件指纹，并非把同一份数据凭空改一个人数。当前v1.5中的`README_版本v1_3.md`是最终v1.3的历史副本。**用户所称另一份“v1.3”尚未与本地某个构建指纹建立唯一对应**；原compact README自称从v1.1提取，也不能据此替用户另一份包定版本。详见[版本命名核查.md](版本命名核查.md)。
