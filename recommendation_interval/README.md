# 29 个推荐配置版本的公开数值核查

v1_4 推荐参数长表共有 285 配置版本；其中 29 版本、18 型号此前不满足四项单值输入要求。这里补做这些公开原值的保守外包络核查，不改写原长表单值字段。

结果：28 版本四项声明数值在全部外包络满足常规门槛，1 版本至少一项在全部外包络未满足，无跨门槛版本。145 个原字段均以完整字符串解析，认读 NEDC/CLTC 工况附注并保留原字串和字段位置；不能从任意附注中抓取数字。故这 29 版本不需要补找原数字，跨目录同配置身份和法律/技术资格认证仍按实际用途取证。

常规门槛：30 分钟最高车速 ≥100 km/h，续驶里程 ≥200 km，声明系统密度 ≥125 Wh/kg，百公里能耗 ≤Y(m)。Y(m) 分别为 .0112m+.4（m≤1000）、.0078m+3.8（1000<m≤1600）、.0048m+8.60（m>1600）。整备质量有多个选项时使用最小及最大 Y；能耗上界不超过最小 Y 则全部选项通过，下界超过最大 Y 则全部选项未通过，其余应保留不确定。所有选项作为保守外包络，不随意配对；工况标签和声明参数不代替原报告认证。

唯一未达常规四条件的版本为 NEQ7000BEVJH11D / NC008570：续航 120 km、密度105 Wh/kg，质量699/715 kg对应Y=8.2288/8.4080，声明能耗8.80高于全部Y。该结论仅为常规声明值筛查，低温例外需要独立报告且不会放宽能耗门槛。

`29配置版本_四技术条件保守外包络核查.csv` 是结果旁表；`145原字段_完整字符串解析与单元格证据.csv` 是解析证据。`仍跨门槛_具体配置字段待补.csv` 只有表头，表示本范围没有数值跨界待补，不表示配置身份已认证。原值的 PDF 字段裁切在 round3 已核对，本轮以这些已核原值作外包络运算。

运行 `python build_recommendation_interval.py` 可重建。验证包含严格解析、分段边界、21.2≤21.2 的等号边界和原表指纹未改变；没有添加检测、车辆或冻结暴露点值。
