# 第1批2014年第54号真实历史公开时间：有界档案补查

本轮新增取得海南税务完整转载、完整法规转载和财政部历史政策报道，但**真实历史首次上线新增闭合为0项，仍无可确认的新历史公开观察上界**。此前round8已经取得主管税库现存索引`pubDate=2014-08-27`；本轮没有重复用这个字段充作实际首发，也没有修改科学日期、研究主数据或交付包。

海南税务[完整54号公告](https://hainan.chinatax.gov.cn/lawlibrary/clgzs/21326.jhtml)当前可读，明确链接第一批车型PDF。页面表头的“发布日期”和“成文日期”都登记为2014-08-26，正文落款却为2014年8月27日。原始HTML、字段定位、SHA和回执均保留；没有自行解释该差异，没有选择8/26作为历史实际公开日。只记录当前官方转载的登记与正文冲突。原目录已同字节回收，本轮未再次下载附件。

财政部[2014年9月18日中国财经报报道](https://www.mof.gov.cn/zhengwuxinxi/caijingshidian/zgcjb/201409/t20140918_1140952.htm)正文明确“8月28日，工业和信息化部会同税务总局印发《免征车辆购置税的新能源汽车车型目录》（第一批）”。这是新增的历史印发事件报道线索。该页属于政策新闻，没有完整54号原公告或第一批车型附件，不能将“印发”、新闻登记日期或报道措辞认证为原公告实际首次上网时间。

上海国家会计学院旗下中国会计视野的[完整法规转载](https://law.esnai.com/view/148900/)有54号正文及第一批PDF实际href，但明示日期是“发文时间2014-8-27”和“实施时间2014-9-1”，没有历史网页发布时间。附件文件名中的`2014912`没有作为公开日。该页2014限定CDX请求返回503临时离线页，留证后没有重试。

公开检索发现的两张旧工信部完整公告入口实际请求均404，协会旧转载503；没有改写URL寻求绕过。财政部原生搜索入口依据门户真实form请求后502，没有重复请求。政府网公共前端的配置和真实API均有保存：2014年8月底至9月初“免征车辆购置税”0匹配，“新能源汽车”只返回无关政务新闻；国务院公报2014查询当前取到10/14条，已取到的条目均非完整54号。检索覆盖有限，无结果不证明原公告当时未公开。

对主管税库与内蒙古两个已知URL，公共Wayback CDX各作2014限定及不限年份最早记录查询，共4次，均HTTP200且响应为`[]`，不是被阻断；具体见[CDX结论](cdx/conclusion.json)。没有历史快照可给出2014实际已上线的观察。空数组不证明其他旧URL没有快照，也不证明当时没有公开。新增法规转载CDX的503与这4次成功空结果分别记录，未将全域概括为不可达。

搜索中的HTTP200验证页、空界面或无关结果均单独分类，不计作补齐。TLS校验保持开启，失败请求未重复；所有成功页与失败响应保留实际回执和哈希。`finalize_public_first.py`只读取本轮保存文件生成字段表、结果和清单，不发网络；`fetch_public_first.py`对已保存回执直接复用。请求以实际回执逐行枚举，结论不要求用户搜非公开技术材料，也不阻塞2023—2024目录状态分析。
